# 腾讯地图 API 错误码速查

API 报错时把原始错误码 + 错误信息如实呈现给用户，禁止自行判断原因
控制台 Key 管理：https://lbs.qq.com/dev/console/key/manage
控制台工单：https://lbs.qq.com/dev/console/ticket/create

## Key 不可用时的本地兜底（110-113 / 190 / 199 等 Key 类错误）

遇到"当前 Key 用不了"的错误码（如 190 Key 无效/过期、199 未开 WebService、110-113 授权类）时，除按下表引导外，可顺带检查本地 `~/.tencentmap/tempkey.json` 是否有其它 Key：

- 存在**当前报错 Key 之外**的其它 Key（`__manual__` 手动固定的，或申请记录），且未过期（`expire_time` 晚于当前时间）→ 轻提示用户："检测到本地还有另一个腾讯位置服务 Key，是否换用它重试一次？"，用户同意后用 `TmapClient(key="其它Key")` 重新调用。
- 本地其它 Key 也都已过期 → 按"临时额度到期"引导：前往 https://lbs.qq.com 分配正式额度，或按 `tempkey-guide.md` 重新申请。
- 本地没有其它 Key → 直接按下表错误码引导用户处理。

> 仅"轻提示 + 用户确认后重试"，不自动替换用户指定的 Key。

## 鉴权 / 配额类

| 错误码 | 原因 | 操作步骤 |
|--------|------|----------|
| 110 | 请求来源未授权 | 在控制台 Key 管理页找到对应 Key，检查 Referer 白名单或 IP 白名单是否包含当前请求来源 |
| 111 | 签名验证失败 | 在控制台找到对应 Key，点击编辑，将正确的 Secret Key 填入后保存 |
| 112 | IP 未被授权 | 在控制台找到对应 Key，编辑 IP 白名单，添加当前出口 IP |
| 113 | 功能未授权 | 在控制台找到对应 Key，编辑其配置，开启所需 API 权限 |
| 120 | QPS 超限 | 降低调用频率，或在「配额管理 → Key 额度」中调整该 Key 的 QPS 配额 |
| 121 | 日调用量达上限 | 在「配额管理 → Key 额度」中调整日调用量配额 |
| 160 | sig 不支持此请求类型 | — |
| 161 | sig 不支持和非 object POST JSON 一起用 | — |
| 190 | Key 无效 | 确认该 Key 是否存在、是否被删除或已过期 |
| 199 | Key 未开启 WebService | 控制台 → 应用管理 → 我的应用 → 找到 Key → 编辑 → 勾选 WebService API |

## 参数错误（301-408）

错误码 301-408 统一为「参数错误」，按报错信息中的具体说明修正即可。

## 系统错误（500+）

后端异常，前往控制台创建工单报备。
